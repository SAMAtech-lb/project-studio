Scope: portfolio template for a graphic designer (Iris Novak, fictional). Mode: Experience. Code-led (no image generation used).

## Direction contract

THESIS: The portfolio is the designer's own design annual: a numbered index of entries with credits, not a hero-plus-card-grid. Refuses the split photo hero and row of equal project cards.

OWN-WORLD: White paper, ink #111318, one process-magenta #e6007e used as the annual's colour (entry numbers, active filter, rule marks), grey stock #f3f3f0 for alternating signatures. Familjen Grotesk, heavy display, tabular numerals. Hairline rules, entry numbers "No. 014", credit lines. Images sit in strict columns, no rounded cards.

STORY: Visitor sees the work first, understands breadth (branding, packaging, editorial, posters, type), opens a case study, trusts via clients/awards/testimonials, then starts a project through the contact form.

FIRST VIEWPORT: Name huge flush-left across the width; right column lists the index (count, disciplines, years); three cover images in a strict row below the name; header with monogram, nav and "Start a project".

FORM: Design annual catalogue, candidate 7 of 7. seed:096e3fe30a913438. Raises: (teletext) every entry addressed by its number and deep-linkable via #no-014; (Miura sheet) one filter control re-sorts the index table and image grid together.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
